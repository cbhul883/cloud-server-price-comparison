## 比“哪家便宜”更重要的三个坑

**首购价和续费价是两回事。** 低价款基本是新用户专享、一折上下的价格，第二年续费回到接近原价，首月便宜续费翻倍的情况在低价服务器里非常普遍。有个实用的判断办法：把续费规则写在明面上的商家，账反而好算——比如腾讯云蜂驰型2核4G首购416.92元起，官方明确续费折扣随时长递减（1个月7折、1年5.5折、3年3.9折起）。多数低价款不会在活动页标注续费价，下单前到订单确认页看一眼那一行数字，能省掉第二年被动的麻烦。

**带宽和流量限制藏在配置表最后几行。** 有些1M带宽的机器，打开图片稍多的网页都费劲。同样是“最便宜”，28元一年对应的是1M级体验加上200GB月流量，36元对应的是3M带宽不限流量，差价8块钱，体验差出一截。比价时把带宽、流量、是否含公网IP三行看完再决定。
